## 2. Qué incluye el piloto (propuesta de alcance)

**Fase 1 — Conexión (semanas 1-3)**
- Relevamiento técnico y accesos de solo lectura.
- Conexión de las 5 fuentes núcleo: Recreo Lovers, Recreo Rex, facturación Qbiz, tráfico y PQR.
- Modelo de identidad: definir qué identificador manda para unir registros (cédula / mail / teléfono / placa) y qué hacer con los que no matchean.

**Fase 2 — Configuración (semanas 3-5)**
- Carga del criterio de negocio: qué es un visitante, qué es un cliente activo, cómo se cuenta una compra cruzada, qué es tráfico peatonal vs. auto.
- Permisos por rol: Relacionamiento, Operaciones, Finanzas, Gerencia.
- Validación con Paulina y su equipo sobre 20 preguntas reales.

**Fase 3 — Operación y adopción (semanas 5-12)**
- Agente disponible para el equipo del área.
- Set de reportes automáticos que reemplazan lo que hoy se arma a mano en Power BI.
- Capacitación y acompañamiento.

**Fuera de alcance (explícito, para que no lo pidan después):**
- Envío de campañas. El agente puede segmentar y preparar el segmento; el envío se hace en Icomm / KOMMO / WhatsApp.
- Escritura sobre sistemas. Todo es lectura sobre réplica.
- Vinculación automática de patente con persona: hoy no existe el dato. Se puede enriquecer con el flujo de Recreo Lovers si ellos lo implementan.

## 3. Estructura de precio (los números los define Joaco)

**Componentes a cotizar:**
1. **Setup / implementación** — una vez. Cubre conexión de 5 fuentes, modelo de identidad, configuración y capacitación.
2. **Fee mensual** — incluye agente en producción, hasta N fuentes, N usuarios y un paquete de horas de soporte.
3. **Fuentes adicionales** — las 5 restantes (Wifi, Social Scan, Urbapark, Icomm, app) como add-on.
4. **Módulo de enriquecimiento de placa** — opcional, si quieren cruzar auto con cliente.
5. **Horas extra de soporte** — después del paquete.

**Datos que faltan para cerrar números (pedir en la respuesta):**
- ¿Cuántos usuarios van a consultar el agente? (para dimensionar licencia)
- ¿La facturación de Qbiz está en un motor de base de datos accesible o solo por exportación?
- ¿Quién es el referente técnico del Departamento de Sistemas para dar accesos?
- ¿El piloto tiene fecha de inicio y duración definida? (recomendado: 90 días con revisión a los 30)
